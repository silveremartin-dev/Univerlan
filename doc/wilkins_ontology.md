Version: 1.0  
Status: Canonical

## 1. Philosophical Grounding

In 1668, philosopher John Wilkins published *An Essay towards a Real Character and a Philosophical Language*, seeking to classify all human knowledge into universal categorical roots and derive concepts compositionally rather than memorizing thousands of arbitrary root words.

In Univerlan, designed for inter-system trade and clear operational protocols, we adopt Wilkinsian **vectoral and categorical decomposition**. Instead of burdening the speaker and listener with separate idiosyncratic verbs for every slight directional nuance, verbs of kinetic action, state transition, and manipulation are built from transparent base roots and directional/relational vectors.

---

## 2. Kinetic Vectors: The `mov` (Move) Matrix

The foundational root for motion is `mov` (/mɔv/). By attaching spatial and egocentric vectors, complex English verbs decompose into unambiguous combinations:

| Concept / English Verb | Univerlan Compound | Meaning Breakdown |
|---|---|---|
| **lift / elevate / raise** | `mov-up` | move upward along the vertical vector |
| **drop / fall / lower** | `mov-don` | move downward |
| **pull / drag towards** | `mov-tu-mi` | move towards the speaker / subject |
| **push / repel** | `mov-fro-mi` | move away from the speaker / subject |
| **enter / penetrate** | `mov-in` | move inside the target boundary |
| **exit / leave / disembark** | `mov-ut` | move outside the target boundary |
| **advance / step forward** | `mov-fowad` | move forward along trajectory |
| **retreat / back up** | `mov-bak` | move backward along trajectory |
| **circle / orbit / bypass** | `mov-arond` | move in a circular / perimeter path |
| **cross / traverse** | `mov-akros` | move across a surface or divide |

### Example in Operation:
- *English:* "Please lift the container and push it into the cargo hold."
- *Univerlan:* `Pliis mov-up de kontener and mov-fro-mi it in de kargo hold.`

## 3. Causative and State Transitions: `mek-` and `be-`

Instead of creating hundreds of specialized adjectives and verbs for physical states:

| Base State | Causative Form (`mek-` = make) | Static State (`be-` = state) |
|---|---|---|
| `hot` (hot) | `mek-hot` (to heat, to cook) | `be-hot` (to be hot, warmth) |
| `kold` (cold) | `mek-kold` (to cool, refrigerate) | `be-kold` (to be cold, chill) |
| `open` (open) | `mek-open` (to open, unseal) | `be-open` (openness) |
| `klos` (closed) | `mek-klos` (to close, lock) | `be-klos` (closure) |
| `laiv` (alive) | `mek-laiv` (to revive, animate) | `be-laiv` (life) |
| `ded` (dead) | `mek-ded` (to kill, terminate) | `be-ded` (death) |
| `klir` (clear) | `mek-klir` (to clarify, clean) | `be-klir` (clarity) |

## 4. Instrumental and Agentive Categories

Following Wilkins's taxonomy of tools, agents, and loci:

- **Agent Suffix (`-or` / `-er`):**
  - `operat` $\rightarrow$ `operator`
  - `mov-up-er` $\rightarrow$ crane, elevator, forklift (literally "lifter")
  - `sel` $\rightarrow$ `seler` (merchant)
  - `bay` $\rightarrow$ `bayer` (buyer, client)

- **Instrument Suffix (`-tul` / `-masin`):**
  - `mov-tul` $\rightarrow$ engine, thruster
  - `vju-tul` $\rightarrow$ telescope, screen, sensor (view-tool)
  - `kom-tul` $\rightarrow$ communicator, radio (comm-tool)

- **Place / Station Suffix (`-rum` / `-zon` / `-bas`):**
  - `kargo-zon` $\rightarrow$ cargo bay / dock
  - `slip-rum` $\rightarrow$ crew quarters (sleep room)
  - `treid-bas` $\rightarrow$ trading outpost

## 5. Pragmatic Efficiency & Signal Integrity

In a subspace radio burst or noisy atmospheric transmission, idiosyncratic English idioms often fail due to dropouts. A message like:
> "He pulled the lever, then pushed the hatch open and lowered the cargo."

Becomes in Univerlan:
> `Hi mov-tu-mi de lever, den mek-open de hac and mov-don de kargo.`

Every operational action is immediately parseable, even with partial packet loss, because each semantic component is composed of primary universal atoms.
