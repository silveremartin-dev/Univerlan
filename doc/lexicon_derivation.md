## 3. Productive Affixes

- `-er` / `-or` : Doer / agent (`treid` $\rightarrow$ `treider`, `bay` $\rightarrow$ `bayer`)
- `-tul` : Instrument or tool (`vju` $\rightarrow$ `vju-tul` = visual sensor)
- `-rum` : Dedicated chamber (`slip` $\rightarrow$ `slip-rum` = crew quarters)
- `-li` : Manner adverbializer (`kwik` $\rightarrow$ `kwikli` = quickly)
- `-s` / `-es` : Plural marker (`planet` $\rightarrow$ `planets`, `boks` $\rightarrow$ `bokses`)
- `-ing` : Continuous active participle (`go` $\rightarrow$ `going`)
- `-ed` : Uniform past participle and finite past tense (`giv` $\rightarrow$ `gived`, `tek` $\rightarrow$ `teked`)
