## 1. Architecture de la Phrase : Ordre SVO Strict

L'Univerlan maintient un ordre syntaxique **Sujet - Verbe - Objet (SVO)** inflexible dans toutes les propositions indépendantes et subordonnées.

```
[Sujet] + [Modificateurs / Auxiliaires] + [Verbe] + [Objet Direct] + [Compléments Prépositionnels / Adverbes]
```

### 1.1 Phrase Affirmative
- *English:* "The captain checks the navigation computer."
- *Français :* « Le capitaine vérifie l'ordinateur de navigation. »
- *Univerlan :* `De kapten cek de nav-kompjuta.`

### 1.2 Phrase Négative
La négation est universellement marquée par la particule `no` placée **immédiatement avant le verbe** ou l'auxiliaire modal :
- `Mi no no` = "I do not know" / « Je ne sais pas »
- `De treider no goed tu de stasion` = "The trader did not go to the station" / « Le marchand n'est pas allé à la station »
- `Wi no wil weit` = "We will not wait" / « Nous n'attendrons pas »

### 1.3 Phrase Interrogative
Deux modes d'interrogation sont autorisés :
1. **Questions ouvertes (avec mot interrogatif) :** Le mot interrogatif se place en tête sans inversion sujet-verbe :
   - `Wer yu go?` ("Where do you go?" / « Où vas-tu ? »)
   - `Wat yu si?` ("What do you see?" / « Que vois-tu ? »)
   - `Wai hi spik wit de cild?` ("Why does he speak with the child?" / « Pourquoi parle-t-il avec l'enfant ? »)
   - `Wen de stat-xip kom?` ("When does the starship arrive?" / « Quand le vaisseau arrive-t-il ? »)
   - `Hau mac kredit it kost?` ("How many credits does it cost?" / « Combien de crédits cela coûte-t-il ? »)

2. **Questions fermées (Oui/Non) :**
   - Par intonation montante à l'oral avec point d'interrogation `?` à l'écrit : `Yu is redi?` (« Tu es prêt ? »)
   - Ou par la particule interrogative optionnelle `ku` en tête de phrase pour transmission radio bruitée : `Ku yu is redi?`

### 1.4 Phrase Impérative
L'impératif utilise la racine verbale nue, précédée optionnellement de `plis` (s'il vous plaît) :
- `Mek-open de eostok!` = "Open the airlock!" / « Ouvrez le sas ! »
- `Plis weit for de pilot.` = "Please wait for the pilot." / « Veuillez attendre le pilote. »

## 2. Système Pronominal & Possessifs Réguliers

Le système pronominal d'Univerlan élimine les déclinaisons casuelles archaïques (*he/him/his*, *they/them/their*). Le rôle grammatical est déterminé uniquement par la position dans la séquence SVO.

### 2.1 Tableau Général des Pronoms Personnels

| Personne | Sujet / Objet | Possessif Déterminant (`-n`) | Possessif Absolu | Réfléchi (`-self`) |
|---|---|---|---|---|
| **1re singulier** | `mi` (je / moi / me) | `min` (mon / ma / mes) | `min` (le mien) | `miself` (moi-même) |
| **2e singulier** | `yu` (tu / toi / te) | `yun` (ton / ta / tes) | `yun` (le tien) | `yuself` (toi-même) |
| **3e singulier (animé masc)** | `hi` (il / lui) | `hin` (son / sa [à lui]) | `hin` (le sien) | `hiself` (lui-même) |
| **3e singulier (animé fém)** | `xi` (elle) | `xin` (son / sa [à elle])| `xin` (le sien) | `xiself` (elle-même) |
| **3e singulier (inanimé/neutre)**| `it` (il / elle / ça) | `itn` (son / sa) | `itn` | `itself` (lui-même) |
| **1re pluriel** | `wi` (nous) | `win` (notre / nos) | `win` (le nôtre) | `wiself` (nous-mêmes) |
| **2e pluriel** | `yus` ou `yu` (vous) | `yusn` / `yun` (votre) | `yusn` | `yuselfs` (vous-mêmes) |
| **3e pluriel** | `dey` (ils / elles / eux) | `deyn` (leur / leurs) | `deyn` (le leur) | `deyselfs` (eux-mêmes) |

### 2.2 Pronoms Démonstratifs
- `dis` = ceci, ce, cet, cette (proximité spatio-temporelle)
- `dat` = cela, ça, ce, cet, cette (éloignement)
- Pluriel démonstratif : `dis mans` (ces personnes-ci), `dat xips` (ces vaisseaux-là).

### 2.3 Pronoms Relatifs
- `hu` : relatif pour les personnes (« qui, que ») &rarr; `De man hu spik is min fada.`
- `dat` ou `wic` : relatif pour les objets et concepts &rarr; `De xip dat travel is fast.`

## 3. Morphologie Nominale & Pluriel Universel

### 3.1 Zéro Genre Grammatical
Les noms sont strictement neutres. Il n'y a pas d'accord en genre sur les articles, adjectifs ou participes.
Pour spécifier explicitement le sexe biologique d'un être vivant :
- Préfixe masculin : `man-` (ex: `man-doktor`, `man-kat`)
- Préfixe féminin : `woman-` (ex: `woman-doktor`, `woman-kat`)

### 3.2 Pluriel Régulier Invariable en `-s` / `-es`
Aucun pluriel irrégulier n'existe en Univerlan :
- `cild` (enfant) &rarr; `cilds` (enfants) [Adieu *children*]
- `man` (humain/homme) &rarr; `mans` (humains/hommes) [Adieu *men*]
- `woman` (femme) &rarr; `womans` (femmes) [Adieu *women*]
- `tut` (dent) &rarr; `tuts` (dents) [Adieu *teeth*]
- `fut` (pied) &rarr; `futs` (pieds) [Adieu *feet*]
- `fix` (poisson) &rarr; `fixs` ou `fixes` (poissons)
- Après siffante (`s`, `z`, `x`, `c`), on ajoute `-es` pour la prononciation : `boks` &rarr; `bokses` (boîtes).

### 3.3 Articles Définis et Indéfinis
- **Défini invariable :** `de` (« le, la, les ») &rarr; `de sta` (l'étoile), `de stas` (les étoiles).
- **Indéfini invariable :** `un` (« un, une ») &rarr; `un xip` (un vaisseau), `un koloni` (une colonie).
- Pour exprimer l'indéfini pluriel (« des »), on emploie `som` (quelques/des) ou simplement le nom au pluriel : `som mans` ou `mans`.

## 4. Système Verbal Intégral (Zéro Verbe Irrégulier)

En Univerlan, **tous les verbes** suivent la même conjugaison analytique et suffixale invariable. Les plus de 200 verbes irréguliers de l'anglais historique et les 3 groupes du français sont totalement uniformisés.

### 4.1 Forme de Base (Infinitif & Présent Général)
Le radical nu sert d'infinitif et de temps présent à toutes les personnes :
- `mi go` = je vais
- `yu go` = tu vas
- `hi go` = il va (aucune marque `-s` de 3e personne)
- `wi go` = nous allons
- `dey go` = ils vont

### 4.2 Passé Défini Invariable : Suffixe `-ed`
Le suffixe `-ed` s'ajoute directement sur la racine :
- `go` &rarr; `goed` (je suis allé, j'allais) [remplace *went*]
- `tek` (prendre) &rarr; `teked` (j'ai pris) [remplace *took*]
- `bay` (acheter) &rarr; `bayed` (j'ai acheté) [remplace *bought*]
- `si` (voir) &rarr; `sied` (j'ai vu) [remplace *saw*]
- `sei` (dire) &rarr; `seied` (j'ai dit) [remplace *said*]
- `mek` (faire) &rarr; `meked` (j'ai fait) [remplace *made*]
- `slip` (dormir) &rarr; `sliped` (j'ai dormi) [remplace *slept*]
- `flai` (voler) &rarr; `flaied` (j'ai volé) [remplace *flew*]

### 4.3 Participe Présent / Aspect Continu : Suffixe `-ing`
- `go` &rarr; `going` (allant / en train d'aller)
- `Mi is going tu de stasion` = "I am going to the station" / « Je suis en train d'aller à la station »

### 4.4 Futur Régulier : Auxiliaire `wil`
- `mi wil travel` = "I will travel" / « Je voyagerai »
- `de xip wil kom` = "The ship will arrive" / « Le vaisseau arrivera »

### 4.5 Conditionnel / Potentiel : Auxiliaire `wud`
- `mi wud help yu` = "I would help you" / « Je t'aiderais »
- `if wi hav fuel, wi wud jump` = « Si nous avions du carburant, nous sauterions »

### 4.6 Aspect Accompli (Parfait) : `hav + [Verbe]-ed`
- `mi hav goed` = "I have gone" / « Je suis parti »
- `dey hav finixed de wok` = "They have finished the work" / « Ils ont terminé le travail »

### 4.7 Le Verbe Être (La Copule Universelle `is`)
En Univerlan, `is` est le radical verbal universel pour l'existence et l'état :
- Présent : `mi is`, `yu is`, `hi is`, `wi is`, `dey is` (je suis, tu es, il est...)
- Passé : `ised` (j'étais, j'ai été)
- Futur : `wil is` ou `wil be` (je serai)
- Participe : `ising` (étant)

### 4.8 Voix Passive : `is + [Verbe]-ed`
La voix passive est transparente :
- `De xip is fix-ed bai de enjinia.` = "The ship is repaired by the engineer."
- `De kristal ised bayed.` = "The crystal was bought."

### 4.9 Verbes Modaux Invariables
- `kan` = pouvoir, capacité physique ou autorisation (« can / may »)
- `mas` = devoir impératif, obligation absolue (« must »)
- `xud` = devoir moral, recommandation, conseil (« should »)
- `kud` = pouvoir conditionnel (« could »)

## 5. Adjectifs, Adverbes & Comparatifs Réguliers

### 5.1 Place de l'Adjectif
L'adjectif qualificatif se place **avant le nom** qu'il qualifie :
- `big stasion` = grande station
- `kwik xip` = vaisseau rapide
- `nu kristal batri` = nouvelle batterie à cristal

### 5.2 Dérivation de l'Adverbe de Manière : Suffixe `-li`
Tout adjectif devient un adverbe de manière en lui adjoignant le suffixe `-li` :
- `kwik` (rapide) &rarr; `kwikli` (rapidement)
- `klir` (clair/propre) &rarr; `klirli` (clairement/proprement)
- `saf` (sûr) &rarr; `safli` (en sécurité / sûrement)
- `tru` (vrai) &rarr; `truli` (vraiment)

### 5.3 Comparatifs et Superlatifs 100% Réguliers
Les formes irrégulières (*better/best, worse/worst*) sont abolies au profit des particules universelles `mor` et `most` :
- **Comparatif de supériorité :** `mor + [Adjectif] + dan`
  - `mor gud dan` = meilleur que (adieu *better*)
  - `mor bad dan` = pire que (adieu *worse*)
  - `mor kwik dan` = plus rapide que
- **Superlatif absolu :** `de most + [Adjectif]`
  - `de most gud xip` = le meilleur vaisseau (adieu *best*)
  - `de most big planet` = la plus grande planète
- **Égalité :** `as + [Adjectif] + as`
  - `as strong as metal` = aussi fort que le métal

## 6. Système Prépositionnel & Relations Spatio-Temporelles

Les prépositions d'Univerlan sont univoques et évitent toute ambiguïté polysémique :

| Préposition | Signification Principale | Exemple |
|---|---|---|
| `in` | Intériorité spatiale ou temporelle (dans, en) | `in de stasion` (dans la station) |
| `ut` / `ut-fro` | Extériorité (hors de) | `ut de kabin` (hors de la cabine) |
| `on` | Contact sur une surface supérieure (sur) | `on de tebel` (sur la table) |
| `onda` | Infériorité verticale (sous) | `onda de flor` (sous le plancher) |
| `ova` | Supériorité verticale sans contact (au-dessus) | `ova de planet` (au-dessus de la planète) |
| `tu` | Direction vers un but, attribution (à, vers) | `go tu de dok` (aller au quai) |
| `fro` | Origine, provenance, cause (de, depuis) | `kom fro de ert` (venir de la Terre) |
| `wit` | Accompagnement, moyen (avec) | `travel wit frends` (voyager avec des amis) |
| `witut` | Privation (sans) | `witut fuel` (sans carburant) |
| `for` | Destination, bénéficiaire, durée (pour) | `fud for de kru` (nourriture pour l'équipage) |
| `bifor` | Antériorité temporelle ou spatiale (avant, devant) | `bifor de jump` (avant le saut) |
| `afta` | Postériorité temporelle (après) | `afta de landing` (après l'atterrissage) |
| `during` | Simultanéité (pendant, durant) | `during de nait` (pendant la nuit) |
| `bitwin` | Position intermédiaire entre deux entités | `bitwin tu stas` (entre deux étoiles) |
| `arund` | Trajectoire circulaire ou proximité (autour de) | `orbit arund de lun` (orbite autour de la lune) |
| `tru` | Traversée (à travers) | `tru de asteroid belt` (à travers la ceinture) |

## 7. Boussole Sémantique & Matrice Wilkinsienne

Inspiré par John Wilkins (1668), l'Univerlan décompose les verbes et transitions d'état en **racines relationnelles** combinées à des **vecteurs d'orientation spatiale ou causale**. Cela évite l'apprentissage de verbes idiomatiques obscurs.

### 7.1 Vecteurs Cinétiques de Déplacement (`mov-`)

```
               [mov-up] (lever / monter / grimper)
                  ▲
                  │
[mov-bak] ◄───────┼───────► [mov-fowad]
(reculer)         │         (avancer / progresser)
                  ▼
              [mov-don] (descendre / tomber / couler)
```

- **Axe Vertical :**
  - `mov-up` = lever, hisser, monter, gravir (*lift, raise, ascend, climb*)
  - `mov-don` = descendre, faire tomber, tomber, couler (*fall, drop, descend, sink, lower*)
- **Axe Égocentrique (par rapport au locuteur) :**
  - `mov-tu-mi` = tirer vers soi, attirer (*pull, drag, attract*)
  - `mov-fro-mi` = pousser loin de soi, repousser (*push, shove, repel*)
- **Axe Frontière (Intérieur / Extérieur) :**
  - `mov-in` = entrer, embarquer, monter à bord (*enter, board, embark, penetrate*)
  - `mov-ut` = sortir, débarquer, quitter (*exit, leave, disembark*)
- **Axe Trajectoire (Avant / Arrière) :**
  - `mov-fowad` = avancer, continuer sa course (*advance, proceed*)
  - `mov-bak` = reculer, faire marche arrière, retourner (*retreat, return, back up*)

### 7.2 Vecteurs Causatifs de Transition d'État (`mek-`)
Le morphème `mek-` (faire/rendre) préfixé à un état ou adjectif exprime le verbe transitif causatif :
- `mek-hot` = chauffer, réchauffer (*heat, warm*)
- `mek-kold` = refroidir, rafraîchir (*cool, chill*)
- `mek-open` = ouvrir (*open, unseal*)
- `mek-klos` = fermer, sceller (*close, shut, seal*)
- `mek-klir` = nettoyer, clarifier (*clean, purify*)
- `mek-liv` = ranimer, faire revivre (*revive, resurrect*)
- `mek-ded` = tuer, détruire, achever (*kill, terminate*)
- `mek-saf` = sécuriser, protéger (*secure, safeguard*)

## 8. Affixes Dérivationnels Productifs

L'Univerlan permet de forger de nouveaux mots transparents grâce à une série d'affixes hautement réguliers :

| Affixe | Rôle Sémantique | Racine | Mot Forgé & Signification |
|---|---|---|---|
| `-tul` | Outil, instrument, appareil technique | `kom` (communication)<br>`vju` (vision)<br>`mov` (mouvement) | `kom-tul` (radio/émetteur)<br>`vju-tul` (capteur/scanner)<br>`mov-tul` (moteur/propulseur) |
| `-man` | Personne exerçant une activité / agent | `treid` (commerce)<br>`wok` (travail)<br>`stat` (espace) | `treid-man` (commerçant)<br>`wok-man` (ouvrier)<br>`stat-man` (astronaute/spacien) |
| `-ist` | Spécialiste scientifique ou professionnel | `sayens` (science)<br>`medisin` (médecine)<br>`astronomi` (astronomie) | `sayens-ist` (scientifique)<br>`medisin-ist` (docteur/médecin)<br>`astronom-ist` (astronome) |
| `-nes` | Qualité abstraite (état, condition) | `sik` (malade)<br>`dak` (sombre)<br>`hapi` (heureux) | `siknes` (maladie)<br>`daknes` (obscurité)<br>`hapines` (bonheur) |
| `un-` | Inversion, contraire, négation lexicale | `posibel` (possible)<br>`saf` (sûr)<br>`lok` (verrouiller) | `unposibel` (impossible)<br>`unsaf` (dangereux)<br>`unlok` (déverrouiller) |
| `re-` | Répétition d'une action | `bild` (construire)<br>`stat` (démarrer)<br>`caj` (charger) | `rebild` (reconstruire)<br>`restat` (redémarrer)<br>`recaj` (recharger) |
| `stat-` | Préfixe pour le domaine stellaire/spatial | `xip` (vaisseau)<br>`port` (port)<br>`kart` (carte) | `stat-xip` (vaisseau interstellaire)<br>`stat-port` (spatioport orbital)<br>`stat-kart` (carte stellaire) |

## 9. Système Numérique, Dates & Mesures Interstellaires

### 9.1 Chiffres et Nombres Cardinaux
- 0 : `siro`
- 1 : `wan`, 2 : `tu`, 3 : `tri`, 4 : `for`, 5 : `faiv`, 6 : `siks`, 7 : `seven`, 8 : `eit`, 9 : `nain`, 10 : `ten`
- 11 : `ileven`, 12 : `twelv`, 13 : `tor-tin`, 14 : `for-tin`, 15 : `fif-tin`, 16 : `siks-tin`, 17 : `seven-tin`, 18 : `eit-tin`, 19 : `nain-tin`
- 20 : `twenti`, 30 : `torti`, 40 : `forti`, 50 : `fifti`, 60 : `siksti`, 70 : `seventi`, 80 : `eiti`, 90 : `nainti`
- 100 : `handred`, 1 000 : `tuzand`, 1 000 000 : `miljon`, 1 000 000 000 : `biljon`
- Règle de composition : `twenti-tu` (22), `tri handred forti-faiv` (345).

### 9.2 Nombres Ordinaux
Suffixe ordinal invariable `-t` (ou `-ti`) :
- 1er : `ferst`
- 2e : `sekond`
- 3e : `tord`
- 4e : `for-t`, 5e : `fif-t`, 10e : `ten-t`, 100e : `handred-t`

### 9.3 Unités de Mesure
L'Univerlan adopte le Système International (SI) étendu aux échelles stellaires :
- Distance : `mita` (m), `kilomita` (km), `astronom-junit` (UA), `lait-yiar` (année-lumière), `parsek` (parsec).
- Temps : `sekond` (s), `minut` (min), `awa` (h), `dei` (jour standard), `saikel` (cycle orbital), `yiar` (an standard).
- Masse : `gram` (g), `kilogram` (kg), `ton` (t).
- Énergie : `djul` (joule), `wat` (watt), `kredit` (unité monétaire universelle).

## 10. Règles de Traduction Bidirectionnelle

Le traducteur automatique Univerlan applique le pipeline déterministe suivant :

```
[Texte Source : Français ou Anglais]
        │
        ▼
1. Détection & Résolution des contractions (l', d', j', c', qu', don't, won't)
        │
        ▼
2. Normalisation de la négation (ne...pas -> no, did not -> no)
        │
        ▼
3. Décomposition Wilkinsienne (verbes complexes -> mov- / mek-)
        │
        ▼
4. Régularisation morphologique (verbes passés -> -ed, pluriels -> -s)
        │
        ▼
5. Projection lexicale unifiée (Core Lexicon)
        │
        ▼
6. Nettoyage phonétique bijectif (1 signe = 1 son, IPA)
        │
        ▼
[Texte Cible : Univerlan Standard]
```

## 11. Corpus Opérationnel & Protocoles de Spatioport

Voici les communications standardisées pour les liaisons radio entre stations orbitales et vaisseaux marchands :

```
[RADIO COM - CANEL 12]
PILOT : Halo stasion Alpha-9. Dis is stat-xip 'Orion'. Win xip rikuest mov-in tu dok 4.
STASION : Halo Orion. Yu is klir for aproc. Redi for dok. Mek-open yun eostok.
PILOT : Kopi dat. Eostok is mek-open. Kristal batris is cajiing.
STASION : Welkom tu Alpha-9. Win dok-mans wil asist yun freit. Pis tu yu.
PILOT : Dank yu stasion. Orion out.
```
